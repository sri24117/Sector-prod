# Runbook — onboarding a pilot NGO

1. **Server setup (once):** `cp .env.example .env`; set `DATABASE_URL`, `POSTGRES_PASSWORD`, `CREDENTIAL_ENCRYPTION_KEY` (`openssl rand -base64 32` — losing it makes stored connections unreadable; back it up), leave `ALLOW_PRIVATE_TARGETS` unset. `pnpm install && pnpm db:migrate`. Start api, web, worker (+ Redis).
2. **Signup:** NGO creates an account at `/signup` (FCRA/PAN/12A/80G are self-declared, unverified).
3. **Billing and plan:** the pricing form persists a request and, when Resend is configured, emails both the NGO and `PLAN_REQUEST_NOTIFY_TO`. List it with `docker compose exec api npm run plan-request -- --list requested`, then move it through `contacted`, `invoiced`, and `paid`. Only after payment reconciliation, run `docker compose exec api npm run plan-request -- <requestId> activate <organizationId>`. This assigns the selected plan and records the activation. Growth and Pro remain a founding-member waitlist. The old names `pilot` and `paid` still mean Starter for existing organizations.
4. **Audit:** `/audits` -> Run audit.
5. **WordPress fixes:** install `plugins/wordpress/sector-companion` on the client's site (**staging first — never run on real WP yet**), have them create an Application Password, connect at `/audits`.
6. **Ad Grants (only if FCRA is genuinely held):** verify the FCRA certificate yourself, then `docker compose exec api npm run confirm-fcra -- <organizationId>` (local dev: `pnpm --filter @sector/db confirm-fcra <organizationId>`). Live checks stay off until Google Ads API access is granted.
7. **Content:** set brand voice; record consent BEFORE anyone exports a story naming a beneficiary. LLM env vars must be set.
8. **Password resets (email via Resend):** "Forgot your password?" creates a one-hour, single-use link and emails it from `EMAIL_FROM` (needs `RESEND_API_KEY` and a Resend-verified domain; check with `pnpm --filter @sector/api reset-link -- <email>` which resends it). If Resend is not configured or is down, that command falls back to printing the link — send it yourself (WhatsApp/email). Links work once and sign the user out everywhere.
9. **Is the free audit converting? (Phase 0-1 Goal #1):** `docker compose exec api npm run funnel -- [days]` prints audits run, fix/connect clicks (connect-intent rate), signups that came from an audit, and how many of those ran an audit in the app.
